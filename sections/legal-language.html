СЛОВНИК БЕЗПЕЧНОЇ МОВИ

/// ТРИ РІВНІ — DO / CAREFUL / NEVER

/// ✓ DO — БЕЗПЕЧНО
  • промоакція
  • маркетингова акція
  • офіційні правила
  • номер участі
  • бонусний номер
  • цифровий токен
  • доступ до сервісу
  • визначення переможця
  • пряма трансляція
  • офіційний протокол
  • фінал промоакції
  • взяти участь
/// ⚠ CAREFUL — ВУЗЬКО І РІДКО
  • розіграш
  • виграш
  • переможець
  • приз

Принцип: де можна — заміняй (на «акція», «вручення», «учасник», «авто»), де критично — залишай. Допустимо тільки в живих сторіс/Reels та в офіційних юридичних документах (де термін має юридичне значення). У hero, footer, hashtags, brief, FAQ, checkout, paid ads — НЕ використовуй.

/// ✕ NEVER — НІКОЛИ
  • шанс
  • гра / в грі
  • програв
  • ставка
  • азарт
  • казино
  • лотерея
  • квиток
  • гарантовано виграєш
  • інвестиція в надію
  • останній шанс
  • купи більше = більше шансів

/// ПРИКЛАДИ — ЯК ПЕРЕПИСУВАТИ

Беремо ризиковану фразу — переписуємо в безпечну. Зберігаємо емоцію, прибираємо юридичний ризик.

// РИЗИКОВАНО
«Виграй BMW X5 за 249 грн!»
→
// БЕЗПЕЧНО
«Отримай токен DreamCar за 249 грн та номер участі в промоакції BMW X5. Умови — на сайті.»
// РИЗИКОВАНО
«Твій шанс забрати ключі!»
→
// БЕЗПЕЧНО
«Твій номер участі вже у фіналі.»
// РИЗИКОВАНО
«Ти в грі!»
→
// БЕЗПЕЧНО
«Твій токен активовано.»
// РИЗИКОВАНО
«249 грн — це не ризик, це інвестиція в надію»
→
// БЕЗПЕЧНО
«249 грн — доступ до акції та номер участі»

  • Окремий слайд / сторіс у серії — повна юридична інформація крупно і чітко.
