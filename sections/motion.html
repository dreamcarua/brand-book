/// 10 — АНІМАЦІЇ

MOTION SYSTEM

Стандартні тривалості та easing-функції. Не вигадуй довільні. Наведи курсор на демо — побачиш різницю.

/// ТРИВАЛОСТІ — DURATIONS

/// FAST
150ms
Hover, focus, малі transitions. Швидкі мікро-взаємодії — наведення на кнопку, зміна кольору іконки.
/// BASE
300ms
Стандартні переходи — поява/зникнення модалок, accordion, dropdown. Найчастіше вживане.
/// SLOW
500ms
Драматичні переходи — поява hero-секції, перехід між сторінками. Використовуй обережно.

/// EASING — КРИВІ РУХУ

/// EASE-OUT

RESPONSIVE

cubic-bezier(0.2, 0.9, 0.3, 1)

Стандарт для всього. Швидкий старт, плавне завершення. Відчувається "натуральним".

/// EASE-IN-OUT

SMOOTH

cubic-bezier(0.4, 0, 0.2, 1)

Для довгих і безперервних анімацій. Плавний старт і фініш.

/// EASE-LINEAR

CONTINUOUS

linear

Тільки для безперервних рухів — ticker, прогрес-бари, спінери.

/// ПРИНЦИПИ

/// PURPOSE

АНІМАЦІЯ З ПРИЧИНОЮ

Кожна анімація має ціль — підказати, привернути увагу, дати feedback. Не анімуй для краси.

/// SPEED

ШВИДКО — ЗАВЖДИ КРАЩЕ

Користувач прийшов по авто, а не дивитись на твою анімацію. Базовий час — 300ms максимум.

/// REDUCED MOTION

ПОВАГА ДО НАЛАШТУВАНЬ

Завжди враховуй prefers-reduced-motion. Деякі люди мають вестибулярні розлади.
