/// ІКОНКИ — ICON SYSTEM

Стиль: лінійний (outline), товщина обводки 1.5px, кутові радіуси 2px, розмір 24×24 (стандарт). Бібліотека на основі Lucide — 1000+ іконок з єдиним стилем. НЕ використовуй emoji в продакшні — тільки для соцмереж.

/// ПАТЕРНИ — PATTERNS

Декоративні фонові патерни для упаковки, презентацій, бекграундів соцмереж. 3 базові патерни — змінюємо тільки масштаб, не пропорції.

DIAGONAL ШВИДКІСТЬ

Гонкові смуги під кутом -12°. Для динамічних композицій, banner'ів, брендованої упаковки.

X-MARKS ХРЕСТИКИ

Точні позначки, як на номерному знаку. Для тонких бекграундів, текстур UI.

DOTS ТОЧКИ

Тонкий патерн крапок. Для subtle бекграундів секцій, тонких розділювачів.
