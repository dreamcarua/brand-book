## GitHub Pages чи Cloudflare Pages
**Запитано:** 25.05.2026, Вадиму — `<?>` відповіді немає
**Варіанти:** A — лишити GitHub Pages (ліміт ~100 ГБ трафіку на місяць) / B — перейти на Cloudflare Pages (без ліміту трафіку, але ще один сервіс у ланцюгу).
**Рекомендація:** A, доки трафік не наблизиться до ліміту. Переносити варто разом із рішенням про HTTPS і DNS, одним заходом.
**Заблоковано доки:** не переносимо; будь-яка правка DNS зачіпає і `CNAME`, і зону.

## OG-image: статичний чи динамічний на кожен розділ
**Запитано:** 25.05.2026, Вадиму — `<?>`
**Варіанти:** A — лишити один `og-image.png` на весь сайт / B — генерувати картинку під кожен із 30 розділів.
**Рекомендація:** A. B вимагає зовнішнього сервісу генерації, а сайт свідомо тримається без build-кроку і без залежностей.
**Заблоковано доки:** WebP-версія і оновлення og-image робляться для одного файлу.

## Прибирати `Bebas Neue` з fallback-ланцюга
**Запитано:** 25.05.2026, Вадиму — `<?>`
**Стан:** у CSS досі `'Oswald', 'Bebas Neue', sans-serif`, хоча `Bebas Neue` не завантажується і не має кирилиці.

**Рекомендація:** A — інакше в дизайнера і в користувача різний рендер того самого макета.
**Заблоковано доки:** ланцюг не чіпаємо.

## Чи потрібен цьому репозиторію власний канал звітів у Telegram
**Запитано:** 03.09.2026, Вадиму — `<?>`
**Стан:** секретів `TG_BOT_TOKEN` / `TG_CHAT_ID` у репо немає, воркфлоу звітів немає.
**Варіанти:** A — поставити обидва секрети і додати `report-to-telegram.yml` сюди / B — слати звіти в канал хабу `dreamcar-memory`.
**Рекомендація:** B, якщо канал хабу вже існує: одна стрічка на весь проєкт читається, дві — ні.
**Заблоковано доки:** агент віддає звіт текстом у відповіді, файлів у `reports/` не створює.
