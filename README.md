Навігація має одне джерело: масив `SECTIONS` в `assets/sidebar.js`. Зміст лендінгу, заголовки сторінок, плашки розділів, хлібні крихти і «попередній / наступний» генерує `scripts/build_nav.py`.

## Живі інструменти

- **Voice Linter** — перевірка тексту за спільним лексиконом `assets/lexicon.js` і автозаміна
- **Генератор постів** — PNG 4:5 / 1:1 / 9:16 з власним фото авто, тексти для Instagram, Reels, сторіс, Telegram і email
- **Color Contrast Checker** — WCAG 2.1 AA/AAA
- **Дизайн-токени** — `tokens/dreamcar-tokens.css` і `.json`: темна і світла теми, палітра графіків
- **PWA** — працює офлайн, встановлюється як застосунок

## Ієрархія правил

При конфлікті: **ЗАКОН (09 Legal-safe лексикон) → ГОЛОС (10) → ВІЗУАЛ**. Лексикон не перекриває ніщо.
Канонічний CTA-ритм: **«Бери. Дій. Володій.»**

## Регенерація артефактів

```bash
python3 scripts/build_nav.py            # зміст, заголовки, плашки, prev/next з SECTIONS
python3 scripts/build_search_index.py   # assets/search-index.json
python3 scripts/build_print.py          # print.html (усі розділи)
python3 scripts/brand_lint.py           # лексикон і посилання (CI блокує BLOCK)
```

## Структура

```
index.html               лендінг і зміст (генерується між TOC:START/END)
sections/*.html          37 розділів, кожен самодостатній
print.html               версія для друку і PDF (генерується)
assets/styles.css        єдина дизайн-система сайту
assets/sidebar.js        навігація, пошук, SEO-мета, global-header
assets/lexicon.js        спільний юридичний лексикон для інструментів
assets/search-index.json повнотекстовий пошук (генерується)
tokens/                  дизайн-токени CSS і JSON
service-worker.js        офлайн-кеш (PWA)
```
